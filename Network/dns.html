概要

[Domain Name System]の略。

数字であるIPアドレスを人間が分かりやすく変換する。
Webサイトの表示やメールの送受信などを行う

DNSサーバー

プロパイダのDNSサーバ以外にも様々なDNSサーバーを利用できます
必ずしも速度が上がるわけではありません。
ルートサーバー最上位サーバー
DNSキャッシュサーバー　PC等からの情報を一定期間保持する

パブリックDNSサーバー

DNS over HTTPS

暗号化によりプライバシー保護に有効。

firefoxでのやりかた
  1. 右上3本線を左クリック
  2. [オプション]
  3. [一般]
  4. 右下[ネットワーク設定]の[接続設定]をクリック
  5. 下[DNS-over-HTTPS (DoH) を有効にする] にチェック
