トップレベルドメイン(TLD)

分野別トップレベルドメイン(gTLD: generic TLD)と、国コードトップレベルドメイン(ccTLD: country code TLD)がある。

分野別トップレベルドメイン(gTLD) [.com]や[.net]など、世界中誰でも取得できる。
国コードトップレベルドメイン(ccTLD)
  • [.jp] 日本国内に住所がある組織と個人のみ使用可
  • 「co.jp」日本国登記された法人のみ
  • 「go.jp」日本の政府機関

ドメイン名決め方

  • サイト名、商品名をそのままドメイン名にする
  • 分かりやすく、短めにする。
  • サブディレクトリの方がサブドメインよりseo上有利になることが多い。
