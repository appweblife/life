設定

送信者名

メール送信でアドレスと一緒に表示される名前をGoogleアカウントに登録してある名前から変更

  1. 右上、歯車のマーク「設定」
  2. 「アカウントとインポート」をクリック
  3. 「名前」”情報を編集”をクリック
  4. 「メールアドレスを編集」のウィンドウが表示されます
  5. 表示させたい名前を入力
  6. 「変更を保存」をクリック
  7. さきほど入力した名前になりました

    • 「設定画面」
    • 「送信メール」
    • 「メール作成」

背景

色や画像を設定できます
  1. 右上、歯車のマークの「設定」
  2. 「テーマ」「すべてを表示」をクリック
  3. 好きな画像、カラー、模様を選択します
  4. 「保存」をクリック
  5. 選択した背景に変更されました

文字サイズ

  1. 「作成」から「新規メッセージ」
  2. 左下「A」をクリック
  3. 「TT」をクリック
  4. 表示されるサイズから選択

メールのヘッダー情報

ヘッダー情報確認
  1. 確認したいメールを開きます
  2. 右側たて3つの点をクリック
  3. 「メッセージのソースを表示」をクリック
  4. ソースが表示されます

翻訳

方法1
  1. メッセージを開く
  2. 上部にある「メッセージを翻訳」をクリック
  3. 日本語化しました
方法2 ※上部に「メッセージを翻訳」がないとき
  1. メッセージを開く
  2. 右上部にある”たて３つの点”をクリック
  3. 「メッセージを翻訳」を選択
  4. 日本語化しました

署名


署名の前の「--」は署名と本文との区切りとして表示され、設定から表示させなくすることも出来ます

署名作成

  1. 右上歯車のマークの設定「設定」
  2. 「全般」「署名」
  3. ［+ 新規作成］をクリック
  4. 任意の名前を入力
  5. 表示されるテキストボックスに署名内容を入力
  6. 「デフォルトの署名」
    • "新規メール用"
    • "返信 / 転送用"
      • にそれぞれ必要に応じて署名を選択する
  7. 「返信で元のメッセージの前に署名を挿入し、その前の「--」行を削除する」に必要に応じてチェックを入れる。
    ココにチェックを入れると、元のメッセージの”前”に署名が配置され署名の前の「--」が無くなります。
    • チェック無し（デフォルトの設定）
    • チェックあり
  8. 下にスクロールし［変更を保存］をクリック

署名選択

複数署名を作成し、使い分けることも可能です。
  1. メールを作成
  2. 右下の「署名を挿入」のペンの"アイコン"をクリック
  3. 「署名なし」、または任意の署名を選択

テンプレート（定型文）

設定

  1. 右上「設定」をクリック
  2. 右上「すべての設定を表示」をクリック
  3. 「詳細」をクリック
  4. テンプレート「有効にする」をクリック
  5. 「変更を保存」をクリック

作成

作成登録
  1. 左上「作成」をクリック
  2. メールを作成し文章を入力し選択
  3. 右下たて3つの点をクリック
  4. 「テンプレート」を選択
  5. 「下書きをテンプレートとして保存」を選択
  6. 「新しいテンプレートとして保存」を選択
  7. 「新しいテンプレート名の入力」で名前を入力し保存

使用

挿入
  1. メールを作成
  2. 右下たて3つの点をクリック
  3. 「テンプレート」を選択
  4. 左側から使用するテンプレートの名前を選択しクリック

ラベル

いわゆる”フォルダ機能”になります。 ラベルの作成 幾つか方法があります。
  1. 左側 「新しいラベルを作成」をクリック
  2. 任意の名前を入力

ラベル編集

ラベルの色
  1. 左側から色を指定したいラベルを選択
  2. ラベルの右横たて3つの点をクリック
  3. 「ラベルの色」を選択
  4. 好きな色をクリック
ラベル名の編集 ラベル名の変更
  1. 編集したいラベルを選択
  2. ラベルの右横たて3つの点をクリック
  3. 「編集」をクリック
  4. ラベル名を入力します
ラベル並び替え

ラベルは基本的に数字、アルファベット順に並びます

ラベル名に数字を付けてラベルの順序を変えることができます
表示/非表示

ラベルを右クリックして「非表示」を選択。
もしくは、 「ラベルの管理」から”非表示”にすると左側ラベルリストの「もっと見る」の下に表示されます

  1. 左側「ラベルの管理」をクリック

自動振り分け設定

  1. 振り分け設定をしたいメールを開きます
  2. 右側もしくは上にある、たて3つの点をクリック
  3. 「自動振り分け設定」をクリック
  4. 「フィルタを作成」をクリック＊メールアドレスはすでに入っています。
    • 必要に応じて「ラベル」や「スター」「重要マーク」を付ける、「アーカイブする」などにチェックを入れます。
    • 以前受信したメールも適用させる場合は「〇通の一致するメールにもフィルタを適用する」にチェックをいれます
  6. 新しいラベルの場合、ラベル名をつけます。

送信

基本

  • 左上「作成」をクリック
  • 「宛先」をクリック、必要に応じて右上[CC],[BCC]をクリックし入力
  • 「件名」をクリックし入力
  • 本文を入力
  • 「送信」をクリック

予約送信

PCだけではなくスマホからでも可能 予約送信方法 PCの電源が入ってなくても送信されます。
  1. 送信ボタン横の▽をクリック後、「送信日時の設定」をクリック
  2. 表示される「送信日時の設定」から送信したい日時があればクリックし、なければ「日付と時刻」をクリックします
  3. 表示される左側のカレンダーから日付を選択し、右側で送信時刻を入力後「送信日時を設定」をクリック
  4. 左側「予定」に追加されます
送信予約変更、キャンセル
  1. 左側「予定」から送信予約変更、キャンセルしたいメールを選択し開きます。
  2. 送信予定日時が表示されます。右側「送信をキャンセル」をクリック
  3. 下書きの画面になり、再設定します。

グループ送信

連絡先ラベルを使用して送信します

「連絡先ラベル」について
  1. メールを作成します
  2. 「宛先」をクリック
  3. 「連絡先の選択」ウインドウが表示されます
  4. 右上「連絡先」プルダウンから送信するグループを選択します
  5. 左の「すべて選択」、または送信したいメンバーをクリックします
  6. 右下「挿入」をクリック
  7. 選択したグループの連絡先が追加されます

送信取り消し

送信クリック後、最大30秒まで送信を遅らせ、送信を取り消すことが出来ます

  1. 右上歯車のマークの「設定」
  2. 「全般」
  3. 「送信取り消し」 　任意の秒数を選択します
  4. 下にスクロールして「変更を保存」をクリック

リンク

テキストにリンクを貼る場合
  1. リンク設定するテキストを選択
  2. メール下部にある「リンクを挿入」のアイコンをクリック
  3. リンク先のURLを入力
  4. リンク設定完了
直接URLにリンクを貼る場合
  1. URLを入力し選択
  2. メール下部にある「リンクを挿入」のアイコンをクリック
  3. リンク設定完了

ファイル添付

添付

添付
  1. メールを作成します
  2. メール下部クリップの形の「ファイルを添付」のアイコンをクリック※ファイルサイズは25MGまで
  3. ウィンドウが表示され、添付するファイルを選択します。
  4. ファイル添付が完了しました。

画像挿入

メール内に画像挿入
  1. メールを作成します
  2. 画像を挿入したい位置にカーソルを合わせます
  3. 下の 「写真を挿入」のアイコンをクリック
  4. 「写真を挿入」のウィンドウが表示され「アップロード」をクリック
  5. 画像をドラッグ、もしくは「アップロードする写真を選択」をクリックして画像を選択
  6. メールに画像挿入ができました
スマホ Googleドライブ
  1. メールを作成します
  2. 下にある「Googleドライブを使用してファイルを挿入」のアイコンをクリック
  3. アップロード

返信

基本

送信先

返信送信者のみ返信される
メール右側もしくは下にある左向きやじるしをクリック。

全員へ返信CCを含め全員へ返信される
”ccを含めて全員に返信する場合”は下にある「全員に返信」、もしくは右の三つの点をクリックし「全員に返信」をクリック

送信先やCC、BCCも追加出来ます

  1. 送信先をクリックすると右側にCC、BCCが表示されます
  2. CC、BCCをそれぞれ必要に応じてクリックします
  3. 必要に応じてそれぞれ入力します

元の文表示
元の文は左下の「...」で隠れていて、クリックすると表示されます。

元の文が表示されました
件名 返信メールの件名は、受信メールの件名に「Re: 」が付いたものになります
  1. 件名を変更する場合は左側［件名を編集］をクリックして編集します。
  2. 別ウィンドウが表示され、件名が編集できるようになります

引用返信

元メールの一部を引用符「|」、「>」をつけて挿入します

メール左下「...」をクリックすると隠れている全文が表示される。
  1. 返信したいメールを開きます
  2. 返信をクリックします
  3. 左下の「...」をクリックし元の文を表示させます
  4. 引用したい箇所を選択コピーします
  5. コピーした文を貼り付けます
  6. コピペした箇所を選択し引用ボタン「”」をクリックします。
    （表示されていない場合は 送信ボタンの右となりのAマークの「書式設定オプション」をクリック。）
  7. 引用符「|」が付きました
  8. 「>」にしたい場合は引用箇所を選択し、右端にある「書式をクリア」をクリックします
  9. 引用符「>」が付きました

自動返信

返信用のテンプレートを作成 送信先を設定しフィルタを作成

不在通知

  1. 右上歯車のマークの「設定」
  2. 「全般」「不在通知」

    • 「不在通知ON」にチェック
    • 開始日など期間を設定
    • ”件名”、”メッセージ”を入力、
    • 「連絡先に登録されているユーザーにのみ返信する」にチェックをいれると連絡先に登録されている相手に"のみ"送信することもできます。
  3. 「変更を保存」をクリック
　 　不在通知解除 　
記載内容
  • 「不在期間」
  • 「不在理由」夏季休業など
  • 緊急用の連絡先、別の窓口なども記載しておく
　

アーカイブ

「受信メール」には表示されなくなりますが、削除ではなく”Gmail”には保存されていて「すべてのメール」では表示されます

  • メールを選択し、表示される右の「アーカイブ」のアイコンをクリック。
  • もしくは、アーカイブしたいメールを選択しチェックを入れると上にアイコンが表示されます

スヌーズ

設定した日時になると「受信トレイ」の最上位に表示されます。

  1. 時計のマークのアイコンをクリックし
  2. 日時を設定
  3. スヌーズが設定されると、メールの右側にスヌーズの日程、時刻が表示されます。

検索

上部にある検索窓に入力し検索表示します



is:unread未読メールのみ表示します
filename:jpg:○○に添付ファイル名を指定して表示します。:jpgだとjpg画像が添付されたメールのみが表示されます。
has:attachment添付ファイルがあるメールのみ表示します。
before: 2022/01/01 入力した日付より前のメールを表示します。
after: 2022/01/01入力した日付より後のメールを表示します。

アクセス履歴

ログイン日時やIPアドレス、ブラウザが表示され、不正ログイン等を確認できます

  1. 画面右下「詳細」をクリック
  2. 別ウィンドウが表示され、 アクセスされたWebブラウザや国、IPアドレス、日時が表示されます
